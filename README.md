# Protecting the Ozone Layer

An animated, narrated web course made with [Papermorph](https://github.com/DozenTwelve/Papermorph) from the *Introductory Course to the International Legal Framework on Ozone Layer Protection* workbook.

- `site/ozone/` is the static book: cover and contents (`index.html`) and one folder per lesson. Lesson 1, *Introduction to Ozone Depletion*, is done.
- `books/ozone/` holds the agreed style (`style.json`), the chapter map, storyboards and review sheets.
- `content/ozone/` holds the narration scripts; `tools/ozone/` the tests and helper scripts.

Preview: `python3 -m http.server 8765 -d site`, then open http://localhost:8765/ozone/.

The source workbook is not included. Publishing the lessons openly needs the workbook owner's (Ozone Secretariat / UNEP) permission.
